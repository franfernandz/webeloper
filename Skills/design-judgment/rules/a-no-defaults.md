# Criterion A — Prohibit Default Decisions

## Rule

The agent may not select a solution simply because it is modern, clean, minimal, or habitual in SaaS sites. A pattern is allowed only when it is justified by the business and the chosen art direction.

This criterion does not ban any resource. It bans choosing a resource without a brief-linked reason.

## Failure Mode It Prevents

Reflexive convergence on the current industry aesthetic. The agent reaches for the most probable layout, palette, and component style instead of deriving them from the specific business. The result is a site that could belong to any competitor.

## Default Decisions to Avoid Without Justification

- Hero with a huge left-aligned headline and a mockup on the right.
- Violet or blue gradients used as decoration with no brand reason.
- Rounded cards applied to absolutely everything.
- Bento grids used because they make a design "look modern."
- Generic sans-serif typography with no editorial or functional rationale.
- Repeated sections that all share the same visual structure.

## Correct Form

Incorrect:
> Use a hero with a large headline on the left and a product mockup on the right, because it is the clearest and most modern layout.

Correct:
> Use a full-bleed industrial photograph with an overlaid technical annotation block instead of a left/right hero. The brand sells precision instrumentation to plant engineers, and the reference for the direction is technical manuals, not software landing pages. A mockup-on-the-right hero would position the company as a software startup, which contradicts the brief.

The difference is not the resource. It is that the second version ties the layout to positioning, audience, and art direction.

## Completion Checklist

Before moving on, the agent must be able to answer, for every default pattern that survives into the design:

- Which business fact or art-direction decision requires this pattern?
- Would a competitor in this market plausibly make the same choice? If yes, is that acceptable or is it the signal to change?

If a pattern has no answer, replace it or drop it.

## Interaction With Other Criteria

- Justifying a default requires the visual thesis (criterion B) and evidence (criterion D).
- The justification must outrank trends in the hierarchy (criterion E).

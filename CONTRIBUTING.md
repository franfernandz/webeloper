# Contributing

Thanks for your interest in contributing to Webeloper.

## Ways to contribute

- **Report a bug** — open an issue describing the problem and expected behavior.
- **Suggest an improvement** — open an issue with a clear description of the problem you are trying to solve.
- **Submit changes** — open a pull request. Keep changes focused and explain your reasoning.

## Guidelines

- Respect the project's design principles: no invented facts, conversion-first, clear role boundaries, no over-engineering.
- Agent files use the [opencode](https://opencode.ai) markdown agent format. Keep the frontmatter valid and the instructions self-contained.
- Contract templates are shared across users — do not introduce agency- or client-specific details into the templates.
- Keep documentation and agent instructions in English.
- Do not add unnecessary dependencies.

## Pull request process

1. Fork the repository.
2. Create a branch for your change: `git checkout -b my-change`.
3. Make focused, well-described commits.
4. Open a pull request against `main` and describe what you changed and why.

## Code of conduct

Be respectful and constructive. Harassment or discrimination of any kind is not tolerated.
